# Git-conventies

## Basis

- Gebruik `naam-van-project_projecttype` voor de naamgeving van repositories (bijv. `fetch-the-weather_api`).
- Gebruik `NaamVanProject.ProjectType` voor namespaces (bijv. `FetchTheWeather.Backend`).

- Gebruik Engels voor alle commitberichten en branchnamen.
- Schrijf volledige woorden, geen afkortingen (bijv. "feature" NIET "feat").
- Gebruik streepjes (`-`) om woorden te scheiden in branchnamen (bijv. `feature/error-handling`).

## Branch

- Gebruik NIET direct `main` voor ontwikkeling.
- Gebruik de `dev`-branch voor ontwikkeling.
- Gebruik het voorvoegsel `feature/` voor nieuwe features (bijv. `feature/logging`).
- Gebruik het voorvoegsel `bugfix/` voor bugfixes (bijv. `bugfix/login-issue`).

## Commit

- Gebruik de tegenwoordige tijd (bijv. "Add feature" NIET "Added feature").
- Maak commitberichten kort en bondig (bijv. "Add user authentication").

## Pull Requests

- Gebruik duidelijke titels voor pull requests (bijv. "Add user authentication feature").
- Voeg een beschrijving toe die de wijzigingen uitlegt.
