# Git-conventies

## Basis

- Gebruik Engels voor alle commitberichten en branchnamen.

## Branch

- Gebruik NIET direct `main` voor ontwikkeling.
- Gebruik de `dev`-branch voor ontwikkeling.
- Gebruik het voorvoegsel `feature/` voor nieuwe features (bijv. `feature/logging`).

## Commit

- Gebruik de tegenwoordige tijd (bijv. "Voeg feature toe" NIET "Voegde feature toe").
